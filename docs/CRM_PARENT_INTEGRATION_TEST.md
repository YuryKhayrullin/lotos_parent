# Проверка взаимодействия CRM и кабинета родителя

Дата: 15 октября 2026 года. Актуальный проект кабинета — lotos_parent; прежний parent_lotos удалён по решению владельца. Код lotos_crm не изменялся.

| Сценарий            | Результат                                                                                                                                        |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Настоящая схема CRM | Применены все 12 SQL-миграций lotos_crm к одноразовой PostgreSQL 17. Роль lotos_parent_reader настроена без прав записи.                         |
| Карточка            | Родитель видит ребёнка, филиал и остаток занятий. Внутренний комментарий CRM не возвращается.                                                    |
| Расписание          | Ближайшее занятие появляется; после отмены в CRM исчезает при новом чтении.                                                                      |
| Посещаемость        | «Был» и «Не был» дают 50%; отсутствие отметки считается отдельно. Отметка сохраняется в истории после удаления из текущего состава.              |
| Оплаты              | Сумма и дата читаются из payments. Новый платёж отображается первым, изменение остатка с 7 до 6 видно при новом запросе.                         |
| Права               | Чужой ребёнок и его платежи дают 404. После отзыва связи доступ исчезает. SQL-роль не читает внутренний комментарий и не меняет клиентов.        |
| HTTP-сценарии       | Проверены вход, закрытая регистрация, Origin, пагинация 23 оплат, обновление сессии, создание и отзыв связи, смена пароля и отключение родителя. |
| Операции CRM        | Отдельный доменный прогон CRM: 123/123 тестов, включая оплату, расписание, посещаемость, конкурентные и повторные запросы.                       |

Команды: npm run test:contract; PARENT_TEST_SKIP_BROWSER=1 npm run test:integration; npm test; npm run typecheck; npm run format:check; npm run build. Все перечисленные проверки прошли.

Ограничения: в контрактном тесте данные CRM записаны SQL, а операции через HTTP-маршрутизатор CRM проверены отдельно, в другой одноразовой базе. Сквозной путь «HTTP CRM → HTTP кабинета» в одной базе пока не проверен. Browser/UI-тест Playwright не выполнен: Chromium отсутствует, а скачивание с cdn.playwright.dev завершилось ошибкой DNS EAI_AGAIN. Режим PARENT_TEST_SKIP_BROWSER явно пропускает браузер, остальные HTTP/БД проверки выполняет.

Демонстрационный маршрут удалён: пользовательский интерфейс больше не содержит фиктивных карточек. Локальная отдельная база аккаунтов родителей подготовлена. Облачная связка lotos_parent с отдельной родительской базой Supabase, ограниченной ролью в рабочей CRM и Vercel ещё не настроена. Живые данные и доступность из российских сетей этим прогоном не проверены. Перед выпуском выполнить env:check, проверить связь одного родителя на staging и повторить UI-тест с Chromium.
