# Публичный каталог пробных занятий

Источник названий, адресов, метро и фотографий — [страница «Наши бассейны» LOTOS](https://sportclublotos.ru/locations), сверена 20.11.2026. Карточки хранятся в `lib/trial-locations.ts`, фотографии в `public/pools` (WebP шириной до 640 px). Страница не запрашивает изображения с Tilda при открытии.

Каталог Яндекс Карт показывает локации клуба даже при недоступной CRM. Для отправки заявки требуется настроенное согласие, однозначное совпадение адреса и названия с филиалом CRM и опубликованное направление. Для остальных карточек доступен звонок. Каталог расписания использует прежний API.
